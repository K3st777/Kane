# Pacote de Distribuição Android — Kane v1.0.0

Este diretório contém os artefatos compilados prontos para publicação no GitHub Releases.

## Arquivos Disponíveis
- `kane-v1.0.0.apk`: Aplicativo Android pronto para instalação direta (compatível com Android 7.0+).

## Instruções para Publicar no GitHub Releases
1. Acesse o repositório no GitHub: `https://github.com/K3st777/Kane/releases`.
2. Clique em **"Draft a new release"**.
3. Crie uma nova tag (ex: `v1.0.0`).
4. Selecione a branch `develop` ou `main`.
5. Arraste e solte o arquivo `kane-v1.0.0.apk` na caixa **"Attach binaries by dropping them here or selecting them"**.
6. Cole as notas de versão fornecidas no relatório e clique em **"Publish release"**.
